# NuvaMovies Plugins

Plugin de telenovelas latinoamericanas para CloudStream.

## Novelas360Provider

Plugin para ver telenovelas completas de novelas360.com

### Características:
- ✅ Búsqueda de telenovelas
- ✅ 5 categorías principales (Destacadas, Estrenos, Más Vistas, etc.)
- ✅ Listado de episodios/capítulos
- ✅ Soporte para 12 hosts de video (StreamWish, Doodstream, Filemoon, Voe, etc.)

### Instalación:

1. Abre CloudStream
2. Ve a: `Ajustes → Extensiones → Añadir repositorio`
3. Pega esta URL:
   ```
   https://raw.githubusercontent.com/hellokitty009535-crypto/nuva-plugins/builds/repo.json
   ```
4. ¡Listo! El plugin se descargará automáticamente.
